# Canlı Sahne · Havayolu dağıtımı PoC

"Havayolu Dağıtımının Görünmeyen Yolculuğu" PoC videosunun yayın sayfası (GitHub Pages).

- `index.html`: oynatıcı, dört kanal ve üç dönemin (Bugün / Geçiş / Hedef) kısa açıklaması, dünya rakamları
- `havayolu-dagitimi-donemler.webm`: yaklaşık 70 sn, 1080p, VP9 (sessiz, altyazılı)
- `kapak.jpg`: oynatıcının başlangıç görseli (Geçiş dönemi, katılımcı kararı anı)

Video, `mustafaergan/sahne` deposundaki `video/dagitim.mjs` ile uygulamanın deneme kopyasında, örnek adlarla kaydedildi
(`video/birlestir.py` ile birleştirildi). Akış aynı depoda hazır akış `sarp` ("Havayolu Dağıtımının Görünmeyen Yolculuğu")
olarak tanımlı. Süreler ve takılma oranları temsilîdir.
