# Canlı Sahne · Havayolu dağıtımı PoC

"Havayolu Dağıtımının Görünmeyen Yolculuğu" PoC videosunun yayın sayfası (GitHub Pages).

- `index.html`: oynatıcı ve akışın kısa açıklaması
- `havayolu-dagitimi.webm`: 72 sn, 1080p, VP9 (sessiz, altyazılı)
- `kapak.jpg`: oynatıcının başlangıç görseli

Video, `mustafaergan/sahne` deposundaki `video/havayolu.mjs` ile uygulamanın deneme kopyasında, örnek adlarla kaydedildi
(`video/birlestir.py` ile birleştirildi). Akışın kendisi aynı depoda hazır akış `havayolu` olarak tanımlı.
